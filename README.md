# Hi, I'm **Cansiny** 👋

Full-stack | Agent | AI

I build desktop tools, AI applications, and everyday automation projects, turning small, everyday needs into tools that are easy to use.

## What I'm working on

- [Heybox Daily](https://github.com/Cansiny0320/heybox-daily): A script for daily Heybox check-ins and tasks, with Docker deployment, SMS login, and task progress checks. Can be scheduled with cron.
- [Codex Bili Dragon](https://github.com/Cansiny0320/codex-bili-dragon): A Bilibili companion running in Codex that explores videos based on your interests, writes diaries, shares videos, and handles messages.
- [bili-agent-kit](https://github.com/Cansiny0320/bili-agent-kit): A TypeScript SDK, CLI, and MCP toolkit for connecting agents and applications to Bilibili, covering content search and reading, media downloads and transcription, favorites management, interactions, and creator tools.
- [DSH Bili Whale Dashboard](https://github.com/Cansiny0320/dsh-bili-whale-dashboard): A companion dashboard for the dsh-bili-whale plugin to read diaries, review replies, and manage its persona and activity schedule.
- [Nexlet](https://github.com/Cansiny0320/Nexlet): An open-source desktop toolbox that brings together app launching, clipboard management, calculations, JSON tools, and file search. I also maintain its [plugin ecosystem](https://github.com/Cansiny0320/Nexlet-plugins).
- [Token Speed Tester / Studio](https://github.com/Cansiny0320/token-speed-tester): A tool for measuring LLM and Codex response times and token throughput, with support for analyzing local Codex usage logs.
- [Bilibili Video Summary Agent](https://github.com/Cansiny0320/bilibili-video-summary-agent): An agent that reads Bilibili video subtitles or transcribes audio to generate timestamped summaries and key takeaways.

Feel free to reach out or open an issue on any of my projects.
